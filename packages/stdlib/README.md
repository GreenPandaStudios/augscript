# August core library

The compiler installs this matching package for `august.io`: console, file, and command-line capabilities with native adapters. The unreleased compiler also supplies `august.collections` for bounded half-open integer ranges, pure data processing, stable sorting and bounded isolated worker mapping, and `august.math` for checked integers and exact bounded decimals. The unreleased `august.errors` module adds deliberate typed causes and source context. The unreleased `august.values` module supplies validated calendar dates, exact millisecond durations, HTTP URLs, token IDs, portable relative paths and bounded UTF-8 text. Public contracts and Javadoc are in `august/io`; the [API reference](https://greenpandastudios.github.io/augscript/api/io) explains them.

JSON, time, stores, web helpers, and crypto are optional source packages. Use [the package guide](https://greenpandastudios.github.io/augscript/packages) to add them from a public repository.
